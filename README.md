# 🛒 E-Commerce Mbah Minar

Website platform belanja online (E-Commerce) modern yang dirancang khusus untuk mempermudah transaksi penjualan produk digital maupun fisik dari toko Mbah Minar.

## 🛠️ Teknologi & Stack Coding

Proyek e-commerce ini dibangun menggunakan teknologi web terkini untuk memastikan performa yang cepat dan aman:

*   **Tampilan (Frontend):** HTML5, CSS3, JavaScript (ES6)
*   **Desain/Tata Letak:** Grid & Flexbox (Desain Responsif)
*   **Penyimpanan Data:** LocalStorage (Simpan data keranjang sementara)
*   **Alat Kerja:** VS Code, Git, dan GitHub Pages

---

## 🌟 Fitur Unggulan Website

*   **Katalog Produk Estetik:** Tampilan list produk yang rapi lengkap dengan harga, foto, dan deskripsi detail.
*   **Keranjang Belanja Dinamis:** Fitur tambah produk ke keranjang belanja (Cart) beserta kalkulator hitung total harga otomatis.
*   **Pencarian & Filter:** Memudahkan pembeli mencari produk berdasarkan nama atau kategori tertentu.
*   **Integrasi WhatsApp Checkout:** Pembeli bisa langsung mengirimkan detail pesanan keranjang belanja mereka langsung ke WhatsApp Admin toko.

---

## 📦 Struktur Menu Website

1.  **Home:** Halaman utama yang menampilkan promo terbaru dan produk terlaris.
2.  **Products:** Katalog lengkap seluruh barang belanjaan yang dijual.
3.  **Cart Room:** Tempat pembeli mengecek kembali daftar barang yang akan dibeli sebelum melakukan pembayaran.
4.  **Contact/About:** Informasi alamat toko fisik Mbah Minar serta kontak operasional.
